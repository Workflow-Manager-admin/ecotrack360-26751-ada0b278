# Lightweight React Template for KAVIA

> **⚠️ Important Backend Warning: In-Memory Only — Not for Production/Staging Use**
>
> The current backend is **purely in-memory for demo and testing purposes only**. This means that **ALL data**—including user accounts, authentication credentials, goals, rewards, and any other information—will be **completely lost every time the server restarts**. Any demo users/accounts you create are erased on backend restart, as is all application state.
>
> **Persistent database integration is required for any production or staging deployment.**  
> For real-world use, you **must** connect the backend to a persistent database solution such as MongoDB, PostgreSQL, SQLite, or an alternative.  
> **Never deploy the in-memory-only backend for production, staging, or live environments.**  
> Failing to provide a persistent data store will result in total data loss and high risk to your users' accounts and data.

---

This project provides a minimal React template with a clean, modern UI and minimal dependencies.

## Features

- **Lightweight**: No heavy UI frameworks - uses only vanilla CSS and React
- **Modern UI**: Clean, responsive design with KAVIA brand styling
- **Fast**: Minimal dependencies for quick loading times
- **Simple**: Easy to understand and modify

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

## Customization

### Colors

The main brand colors are defined as CSS variables in `src/App.css`:

```css
:root {
  --kavia-orange: #E87A41;
  --kavia-dark: #1A1A1A;
  --text-color: #ffffff;
  --text-secondary: rgba(255, 255, 255, 0.7);
  --border-color: rgba(255, 255, 255, 0.1);
}
```

### Components

This template uses pure HTML/CSS components instead of a UI framework. You can find component styles in `src/App.css`. 

Common components include:
- Buttons (`.btn`, `.btn-large`)
- Container (`.container`)
- Navigation (`.navbar`)
- Typography (`.title`, `.subtitle`, `.description`)
